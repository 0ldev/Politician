# Code of Conduct

## Our pledge

This is a technical security research project. Everyone who participates — whether opening issues, submitting PRs, or commenting — is expected to engage respectfully and in good faith.

## Expected behaviour

- Be direct and technically precise
- Critique code and ideas, not people
- Accept feedback constructively
- Disclose security issues privately (see [SECURITY.md](SECURITY.md))

## Unacceptable behaviour

- Harassment or personal attacks of any kind
- Sharing or encouraging clearly illegal use of this library against networks you don't own or have permission to test
- Deliberately hostile or bad-faith contributions (e.g. PRs designed to introduce backdoors or supply chain issues)

## Enforcement

Violations may result in comments being removed, PRs being closed without merge, or contributors being blocked from the repository, at the maintainer's discretion.

## Scope

This code of conduct applies within the GitHub repository — issues, pull requests, discussions, and code review comments.
